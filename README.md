# Rimworld - The Army Of Fetid Corpses (Continued) - Combat Extended Patch

Compatibility patch for RimWorld 1.6 that adapts **The Army Of Fetid Corpses (Continued)** to work with **Combat Extended**.

##  Features
 - Weapons — Full rebalance for CE mechanics, including custom "Cleansing" and "Special" ammunition types.
 - Armor — Reworked to fit CE's armor system.
 - Necronoids — All creatures rebalanced for CE combat.

## Required Mods
This patch requires the following mods to be installed and active:

 - [Combat Extended](https://steamcommunity.com/sharedfiles/filedetails/?id=2890901044)
 - [The Army Of Fetid Corpses (Continued)](https://steamcommunity.com/sharedfiles/filedetails/?id=3597124120)
